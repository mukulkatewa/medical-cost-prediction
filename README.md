# Medical Cost Prediction

**Live demo:** https://medical-cost-prediction-s6qe5xjf8tg2t3szb2hbj3.streamlit.app

Predicts individual medical insurance charges from demographic and health
attributes (age, sex, BMI, children, smoker status, region) using a set of
regression models, with the best performer selected automatically on a
held-out test set.

## Dataset

`data/insurance.csv` — 1,338 records, 7 columns (Kaggle "Medical Cost
Personal Datasets").

| Column   | Description                                   |
|----------|------------------------------------------------|
| age      | Age of primary beneficiary                     |
| sex      | Gender of beneficiary                          |
| bmi      | Body mass index                                |
| children | Number of dependents covered                   |
| smoker   | Smoking status                                 |
| region   | Residential area in the US                     |
| charges  | Individual medical costs billed (target)       |

## Approach

- `notebooks/eda.ipynb` — exploratory analysis: distributions, correlation
  heatmap, and the charges-vs-age/smoker relationship that turns out to be
  the strongest signal in the data.
- `src/train.py` — a `ColumnTransformer` pipeline (standard-scaled numeric
  features, one-hot encoded categoricals) feeding four candidate regressors:
  Linear Regression, Polynomial Regression (degree 2), Decision Tree, and
  Random Forest. Each is scored with 5-fold cross-validation on the training
  split and evaluated on a held-out test set; the best model by test R² is
  persisted.
- `src/predict.py` — loads the saved model and scores a single applicant
  from the command line.

## Results (test split, random_state=42)

| Model                  | R²     | RMSE      |
|------------------------|--------|-----------|
| Linear Regression      | 0.784  | 5,796     |
| Polynomial Regression  | 0.867  | 4,551     |
| Decision Tree          | 0.833  | 5,085     |
| **Random Forest**      | **0.868** | **4,527** |

Random Forest is selected and saved to `models/model.joblib`. Full metrics
(including cross-validation scores) are in `models/metrics.json` after
training.

## Usage

```bash
pip install -r requirements.txt

python src/train.py                      # trains all models, saves the best one
python src/predict.py --age 29 --sex male --bmi 27.3 --children 1 \
    --smoker no --region southeast
```
